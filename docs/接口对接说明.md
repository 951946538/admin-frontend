# 接口对接说明

## 基础约定

| 项目 | 说明 |
|------|------|
| Base URL | 开发环境 `/api/v1`（vite 代理到 `http://localhost:8080`） |
| 响应结构 | `{ code, msg, data }`，`code=0` 成功，`code=-1` 失败 |
| 分页参数 | `page`（从 1 开始）、`page_size`（默认 10，最大 100） |
| 登录态 | 当前版本无 token，前端用 `localStorage.user` 保存登录用户 |

## 当前对接的接口（v0.2.0，2026-09-22）

| 方法 | 路径 | 用途 | 前端调用 |
|------|------|------|----------|
| GET | /health | 健康检查 | `src/api/user.js → checkHealth` |
| POST | /api/v1/login | 登录（用户名不存在则自动注册） | `src/api/auth.js → login` |
| GET | /api/v1/users | 用户分页列表 | `src/api/user.js → listUsers` |
| POST | /api/v1/users | 新增用户（仅 username） | `src/api/user.js → createUser` |
| DELETE | /api/v1/users/:id | 删除用户 | `src/api/user.js → deleteUser` |

### 用户对象结构（v0.2.0）

```json
{ "id": 1, "username": "admin" }
```

> v0.1.0 → v0.2.0 变更：users 表仅保留 **id + username** 两列，
> 登录页 `/login` 为独立全屏页面（玻璃拟态卡片 + 渐变背景），
> 路由守卫：未登录自动跳转 `/login`。

## 变更联动流程

1. 后端修改/新增接口 → 更新后端 `docs/API_CHANGELOG.md`
2. 前端更新 `src/api/*.js` 封装，并在本文件"当前对接的接口"表格同步登记
3. 涉及数据库结构变化的，检查后端 `docs/SQL/` 是否有对应新脚本
